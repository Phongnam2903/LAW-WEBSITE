## Assumptions Carried Forward (not open questions, but worth stating explicitly)

- Both MinIO and AWS S3 are never required simultaneously in the same environment (`AS-03` from Phase 1) — `storage.endpoint` unset always means "use real AWS S3", never "use both".
- The `cases` Java package (not `case`) is a language-forced naming deviation from the master prompt's suggested package list, not a design choice — `case` is a reserved Java keyword.
- No business reference/seed data (e.g. actual `roles` rows like `SUPER_ADMIN`) is inserted anywhere in Phase 3 — deferred to the User Management feature in a later phase, to avoid Phase 3 quietly starting business feature implementation.
